# 辨色谱 Logo

- `logo-source.svg`：可编辑的矢量源文件，后续换色或调整细节优先修改此文件。
- `logo-1024.png`：平台上传和宣传素材主文件。
- `logo-512.png`：常用高清版本。
- `logo-144.png`：小尺寸预览版本。
- `logo-wechat-avatar-source.svg`：微信圆形头像专用矢量源文件。
- `logo-wechat-avatar-1024.png`：微信公众平台头像上传文件。
- `logo-wechat-avatar-512.png`：微信头像常用预览版本。

平台后台替换 Logo 不会影响既有测试数据；更新图片后重新提交平台审核即可。
