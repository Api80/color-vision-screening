# 辨色谱

跨端色觉辨别自测工具。使用一套 Taro 4 + React + TypeScript 代码，
构建微信小程序、抖音小程序和 H5。

## 第一版能力

- 测试前设备与环境确认
- 随机化高密度小圆点图案
- L / M / S 三条色觉轴的自适应阈值测试
- 类型方向与辨色困难程度
- 内部作答质量门槛，不向用户展示易误解的评分
- 作答未形成清晰规律时引导重新测试
- 结果仅保存在当前设备
- 明确的医学与职业体检免责声明

## 本地运行

```bash
npm install
npm run dev:h5
```

构建三个目标：

```bash
npm run build:h5
npm run build:weapp
npm run build:tt
```

产物分别位于：

- `dist/h5`
- `dist/weapp`
- `dist/tt`

微信和抖音发布前，需要在对应项目配置中替换正式 App ID。

## 首发接入

- H5：将 `dist/h5` 整个目录部署到支持 HTTPS 的静态站点。
- 微信：使用微信开发者工具导入 `dist/weapp`，填写正式 App ID。
- 抖音：使用抖音开发者工具导入 `dist/tt`，填写正式 App ID。
- 在两个小程序平台补齐主体认证、隐私保护指引、服务类目和用户协议。
- 首次公开投放前，至少选取常见 iOS、Android 和国产屏幕各一台进行人工复测。

## 依赖审计说明

截至 2026-07-26，`npm audit` 会报告 Taro 4.2.1 工具链及其间接依赖中的已知问题，
其中包括项目未使用的 Swiper 组件和仅用于本地构建的开发服务器。npm 给出的自动修复
方案会将多个 Taro 包跨大版本降级，不能安全直接应用。发布时应只部署编译后的静态产物，
不要暴露 Taro 开发服务器；后续应跟随 Taro 官方兼容版本统一升级并重新执行三端回归。

## 重要限制

本版本用于个人色觉自测与了解，不是医疗器械，也没有完成中国人群常模和临床验证。
当前分型与程度不能用于医学诊断、驾照体检或职业准入。

后续临床版本应使用固定并经过色度计校准的显示设备，与异常镜、HRR、D-15
和标准假同色图开展多中心对照验证。
